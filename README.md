# 💻 Meu Portfólio Pessoal

Este é o repositório do meu **site de portfólio pessoal**, desenvolvido para centralizar meus principais projetos, habilidades técnicas, experiências e formas de contato de maneira clara, moderna e responsiva.

🚀 **Acesse o projeto online:** [jorgeandrade.vercel.app](https://vercel.app)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **HTML5** – Estruturação semântica do conteúdo.
* **CSS3** – Estilização, design responsivo (Mobile First) e animações.
* **JavaScript** – Interatividade e dinamismo do site.
* **Vercel** – Plataforma utilizada para o deploy e hospedagem da aplicação.

---

## 📌 Funcionalidades Principais

* **Seção Sobre Mim:** Breve resumo sobre minha trajetória profissional, objetivos e paixão por tecnologia.
* **Projetos:** Galeria com os principais sistemas e páginas que desenvolvi, incluindo links para os repositórios e demonstrações ao vivo.
* **Habilidades (Skills):** Exibição das tecnologias, frameworks e ferramentas que domino.
* **Contato:** Formulário ou links diretos para minhas redes sociais (LinkedIn, GitHub, E-mail).
* **Design Responsivo:** Interface totalmente adaptada para dispositivos móveis, tablets e computadores.

---

## 🚀 Como Executar o Projeto Localmente

Se desejar clonar este repositório e rodar o projeto na sua máquina local, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd portfolio-jorge-andrade
   ```

3. **Abra o projeto:**
   * Você pode abrir o arquivo `index.html` diretamente no seu navegador.
   * Ou abrir a pasta no seu editor de código (como o VS Code) e utilizar a extensão **Live Server** para rodar localmente.
